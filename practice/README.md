# Практические работы

В этих работах вы пишете код для задач, где решение строится вокруг одного
приёма. Тесты проверяют крайние случаи и ограничение по скорости; после запуска
разберите, почему именно этот приём подходит.

| Работа | Тема |
|---|---|
| [04 · Два указателя](04-two-pointers/README.md) | пройти массив с двух сторон или переставить элементы на месте |
| [05 · Скользящее окно](05-fixed-sliding-window/README.md) | переносить состояние от одного отрезка массива к следующему |

Стартовые примеры и объяснения приёмов находятся в [материалах](../materials/README.md).

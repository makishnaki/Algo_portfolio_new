## С чего начать

1. Нажмите **Use this template → Create a new repository**. Кнопка **Fork** не подходит.
2. Склонируйте свой репозиторий в VS Code: **Source Control → Clone Repository**.
3. Создайте окружение: `python3 -m venv .venv`, активируйте его и выполните `pip install -r requirements.txt`.
4. Откройте папку нужной работы из таблиц ниже. Условия и файлы находятся внутри неё.

На Windows создайте окружение командой `py -m venv .venv`, а активируйте:
`.venv\Scripts\Activate.ps1`.

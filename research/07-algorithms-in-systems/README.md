## Если не работает

| Признак | Что проверить |
|---|---|
| `NotImplementedError` | тело функции ещё не написано |
| Падает `test_empty_file` | заголовок собран неверно: у пустого файла размер `0`, а хеш всё равно не пустой |
| Хеш из 40 символов, но не тот | заголовок собран неверно: нет нулевого байта `b"\0"` после размера, лишний пробел или размер посчитан не в байтах |
| Хеш совпадает в тестах, но не с `git hash-object` | команда Git запущена без `--no-filters` или файл прочитан в текстовом режиме: нужен `open(path, "rb")` |
| `TypeError: can't concat str to bytes` | заголовок — строка; переведите его в байты: `"...".encode()` |

# Анализ алгоритмов в профессии программиста

Программист не ищет один «правильный» алгоритм. Он сравнивает рабочие варианты и выбирает тот, который подходит под данные, время и память.

В этой папке — 12 исследований. В каждом нужно получить от ИИ 8 вариантов, проверить их кодом, измерить время и память, посчитать проверки и выбрать решение для двух условий.

## Порядок работы

1. Сначала запишите свою идею.
2. Попросите ИИ предложить 8 вариантов.
3. Реализуйте и проверьте варианты.
4. Сделайте замеры на трёх наборах данных.
5. Заполните таблицу и выберите вариант для каждого сценария.

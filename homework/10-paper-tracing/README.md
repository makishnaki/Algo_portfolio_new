## Задача 1. Пара с суммой (модуль 8)

```python
def pair_sum(nums, target):
    left, right = 0, len(nums) - 1
    while left < right:
        s = nums[left] + nums[right]
        if s == target:
            return left, right
        if s > target:
            right -= 1
        else:
            left += 1
    return None
```

Вход: `nums = [1, 3, 4, 6, 8, 11]`, `target = 10`.

**На листе:** выпишите массив в клетки с индексами. Ниже, по строке на шаг,
отметьте стрелками `left` и `right` и запишите сумму.

## Задача 2. Самая длинная подстрока без повторов (модуль 10)

```python
def longest_unique(s):
    window = set()
    left = 0
    best = 0
    for right, ch in enumerate(s):
        while ch in window:
            window.remove(s[left])
            left += 1
        window.add(ch)
        best = max(best, right - left + 1)
    return best
```

Вход: `s = "abcbdeca"`.

**На листе:** выпишите строку в клетки, по строке на каждый `right`.
Обведите текущее окно рамкой, а буквы, которые убрал цикл `while`,
зачеркните. Справа запишите `best`.

## Задача 3. LRU и FIFO (модуль 20)

Кэш на 3 места. Последовательность запросов:

```text
put a 1, put b 2, put c 3, get a, put d 4, get b, get c, put e 5, get a, get d
```

`get` возвращает значение или `-1`, если ключа нет. LRU вытесняет ключ,
к которому дольше всех не обращались. FIFO вытесняет ключ, который
дольше всех лежит в кэше, и при `get` порядок не меняет. Пройдите
последовательность с обеими политиками.

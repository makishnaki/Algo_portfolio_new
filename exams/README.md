# Тесты и контрольные работы

Когда появится диагностическая, тест или контрольная работа, преподаватель
добавит сюда папку с условиями и правилами выполнения.

Работы этого раздела выполняются только по условиям преподавателя. Использование
ИИ, поиска и автодополнения определяется в инструкции к каждой работе.

# Обновление материалов

После занятия преподаватель добавляет в шаблон конспекты, заготовки и новые
работы. GitHub Actions переносит их в ваш репозиторий каждый день в 06:00 по
Москве.

Обновление заменяет папки `lectures/`, `materials/` и `docs/`, а также страницы
навигации в `homework/`, `practice/`, `research/` и `exams/`. Ваш код, ответы,
заполненные бланки и корневой `README.md` остаются вашими.

Если материал нужен сразу, откройте в репозитории **Actions**, выберите
**«Обновление материалов курса»** и нажмите **Run workflow**. Когда запуск
закончится, нажмите **Sync Changes** в VS Code. Это работает у репозиториев,
созданных кнопкой **Use this template**.

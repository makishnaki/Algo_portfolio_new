# Как приходят новые материалы

Преподаватель добавляет в шаблон новые конспекты, материалы и заготовки работ.
GitHub Actions каждый день в 06:00 по Москве переносит их в ваш репозиторий.

## Что меняется

| Файлы | Что происходит при обновлении |
|---|---|
| `lectures/`, `materials/`, `docs/` | заменяются версией преподавателя |
| `README.md` в `homework/`, `practice/`, `research/`, `exams/` | заменяются: в них находится навигация по выданным работам |
| новые папки и заготовки | добавляются, если их ещё нет |
| ваши ответы, код, заполненные бланки и корневой `README.md` | не меняются |

Не редактируйте материалы преподавателя: следующая синхронизация заменит правку.

## Забрать обновления сразу

1. Откройте свой репозиторий на GitHub и вкладку **Actions**.
2. Выберите **«Обновление материалов курса»**.
3. Нажмите **Run workflow → Run workflow**.
4. После зелёной галочки нажмите **Sync Changes** в VS Code, чтобы файлы появились на компьютере.

Обновление работает, если репозиторий создан кнопкой **Use this template**.

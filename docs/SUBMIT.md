# Как сдавать работы

Каждая работа остаётся в своей папке. Когда она готова, создайте ветку вида
`hw-04`, сделайте коммит и откройте Pull Request из этой ветки в свою `main`.

В сообщении коммита назовите работу и результат: `hw-04: решены задачи двумя указателями`.
В Pull Request достаточно написать, что сделано, какое решение выбрано и чем
оно проверено. Если работа требует замеров или снимка экрана, это указано в её
README.

Подробные действия в VS Code показаны в [разборе Git и GitHub](git/README.md).

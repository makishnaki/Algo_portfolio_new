# Как сдавать работы

Одна работа — одна ветка — один Pull Request в свою ветку `main`.

## Порядок

1. Создайте ветку с номером работы: `hw-01`, `hw-02` и так далее.
2. Заполните файлы в папке работы.
3. Запустите код и тесты из задания.
4. Закоммитьте изменения понятным сообщением: `hw-04: решение двух задач`.
5. Опубликуйте ветку и откройте Pull Request в свою `main`.

В описании Pull Request напишите: что сделано, какой алгоритм выбран, его
сложность по времени и памяти и какие проверки выполнены.

## Перед отправкой

- Все файлы лежат в папке нужной работы.
- Код запускается, а тесты проходят.
- Скриншоты и замеры добавлены, если они требуются заданием.
- Ветка опубликована на GitHub, Pull Request открыт в свою `main`.

Пошаговый разбор работы с Git и GitHub — в [docs/git](git/README.md).
